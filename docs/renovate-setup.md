# Renovate setup (M5-T7a)

The repo ships with a [`.github/renovate.json`](../.github/renovate.json) configured for weekly Monday morning scans. To activate, install the [Renovate GitHub App](https://github.com/apps/renovate) on this repository (Settings → Integrations → Renovate). Once enabled, Renovate will open weekly PRs grouped by package family.
